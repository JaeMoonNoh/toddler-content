# 원본 바뀜 판단 규칙

`pnpm benefit change-texts <폴더>`로 만든 md를 읽고, 원본이 바뀐 카드를 고쳐야 하는지 정할 때 따르는 규칙. md에는 카드마다 **지금 카드 값**과 원문에서 **바뀐 말**만 있다 (`[-지운 말-]{+더한 말+}`, `…`는 바뀌지 않아 줄인 부분).

판단이 갈린 카드만 main이 원문(`pnpm benefit review <slug>`)으로 다시 보고, 운영자가 PR에서 승인한다. **바뀐 말에 없는 내용은 추측하지 않는다.**

## 판단 세 가지

- `keep`: 바뀐 말이 카드 값에 영향이 없다. 예: 문구만 다듬음, 띄어쓰기·줄바꿈만 바뀜, 문의 전화·담당 부서·근거 법령만 바뀜, 카드 값과 이미 같은 내용.
- `edit`: 카드 값을 고쳐야 한다. 금액, 일정(임신 주수·출생 후 며칠), 올해 신청 기간, 신청 방법, 대상, 조건, 이름 중 무엇이 바뀌었는지 적는다.
- `retire`: 사업이 끝났거나(종료·폐지, 사업 기간이 지남) 더는 임신·출산·0~6세 아이를 위한 혜택이 아니다.

애매하면 `edit`으로 두고 `note`에 이유를 적는다. 그냥 넘기는 것(`keep`)보다 사람이 한 번 더 보는 쪽이 낫다.

## 출력

카드마다 하나씩, md 순서대로 JSON 배열 하나.

```json
[
  {
    "slug": "gov24-611000019618",
    "decision": "keep" | "edit" | "retire",
    "fields": ["amount" | "schedule" | "applicationPeriod" | "howToApply" | "audience" | "conditions" | "name"],
    "quote": "바뀐 말을 md에서 그대로 옮김",
    "note": "고칠 값(원문에 적혀 있을 때만) 또는 애매한 점. 없으면 빈 문자열"
  }
]
```

- `fields`: `edit`일 때 고칠 카드 필드. `keep`, `retire`이면 빈 배열.
- `quote`: 판단의 근거가 된 바뀐 말을 `{+…+}`, `[-…-]` 표시 없이 **그대로** 옮긴다. 말을 바꾸거나 요약하지 않는다. `keep`이면 빈 문자열이어도 된다.
- `note`: 새 값은 원문에 숫자·날짜가 그대로 있을 때만 적는다 (예: "금액 30만원 → 50만원"). 계산하거나 짐작한 값은 적지 않는다.

예:

```json
{"slug":"gov24-1","decision":"edit","fields":["amount"],"quote":"최대 50만원 지원","note":"금액 30만원 → 50만원"}
```
