# 혜택 후보 고르기 규칙

`pnpm benefit candidates <지역코드>`로 뽑은 후보 중 사이트에 올릴 것을 고를 때 따르는 규칙. 고른 결과는 판단 파일(JSON)로 적고 `pnpm benefit add <지역코드> <판단.json>`으로 넣는다. 두 판단을 비교할 때는 `pnpm benefit compare-decisions <A.json> <B.json>`을 쓴다. 인천·청주·서울·경기를 정리하면서 정한 기준이다.

후보는 공공데이터에서 키워드로 자동으로 뽑은 것이라 사이트에 맞지 않는 것이 섞여 있다. 항목마다 **지원대상**과 **지원내용** 원문을 보고 판단한다. 원문에 없는 내용은 추측하지 않는다.

## 사이트가 보여주는 범위

- 임신 중부터 영유아기(만 0~6세)까지, 시기별로 받을 수 있는 혜택.
- **출산 후 혜택도 대상이다.** 산후조리비, 출산축하금, 육아휴직 장려금, 보육료, 영유아 검진, 장난감 대여처럼 아이가 태어난 뒤 받는 혜택도 넣는다. "지금 임신 중인 사람이 바로 받을 수 있나"로 판단하지 않는다.
- 출산·육아·입양·난임·아이와 관련된 혜택은 넣는다. 저소득·장애·한부모처럼 특정 대상만 받는 혜택이라도 출산이나 아이가 조건이면 넣는다.
- 시·군·구 보건소의 임산부 등록·검사 서비스(기형아·당뇨 검사, 엽산제·철분제, 유축기 대여)도 시·군·구마다 넣는다.

## 빼는 기준

빼는 항목은 아래 번호 중 하나로 이유를 적고, 이유에는 원문 문구를 짧게 인용한다.

1. **출생 시기 제한.** 원문 대상이 이미 지난 출생 시기로 정해져 있어서 앞으로 태어날 아이가 받을 수 없다. 예: "2016년 출생 아동", "2024년 12월 31일까지 출생한 셋째 이상", "2021.12.31.이전 출생아까지만 지급". 지원대상과 지원내용에서 이런 문구를 꼭 찾는다. "2025년 1월 1일 이후 출생아부터"처럼 시작일만 있는 것은 앞으로 태어날 아이도 받으니 빼지 않는다.
2. **아이·출산과 관계없는 일반 대상.** 출산이나 아이 조건이 없는 노인, 장애인 전체, 저소득층 전체, 행려자 지원, 건강보험료 지원, 일반 건강검진. 자녀 수(다자녀)나 임신·출산·양육이 조건이면 일반 대상이 아니라서 넣는다.
3. **부모가 신청하는 혜택이 아님.** 시설이나 기관이 대상인 것, 특정 회사 직원만 받는 기업 인센티브, 시설 이용료를 대상별로 깎아 주는 감면 규정(경로우대자·국가유공자 감면 등).
4. **임신·영유아와 거리가 멂.** 가정위탁 아동, 학대피해아동, 학령기(초등학생 이상, 만 7세 이상) 아동만 대상인 것(결식아동 급식, 예체능 수강료, 진로), 청소년·청년 대상. 만 0~6세 아이가 대상에 들어가면 넣는다. 예: 3~5세 보육료 지원은 넣는다.
5. **시·도 사업을 시·군·구에서 접수만 받음.** 같은 사업이 시·도 혜택(이미 사이트에 있는 것 포함)과 시·군·구 항목으로 따로 있으면 시·도 것 하나만 둔다. 시·군·구에서 받으면 그 지역 사람에게 같은 혜택이 두 번 보이기 때문이다. 시·군·구가 자체 예산으로 하는 사업(시·군·구 이름이 붙은 출산축하금, "(자체)" 표시 등)은 넣는다.
6. **전국 혜택과 같은 사업.** 전국 혜택을 시·도나 시·군·구가 그대로 접수만 받는 것. 예: 산모·신생아 건강관리 지원(건강관리사 파견).
   - 자기 예산으로 **더 주는 것은 다른 혜택**이라 넣는다. 예: 산모·신생아 건강관리 **본인부담금** 추가 지원, 난임 시술 **약제비**, **한의약** 난임 치료, 입양축하금, 미숙아 RSV 예방접종비.
   - **대상이 다르면 다른 사업**이다. 예: 남성장애인(배우자가 출산) 출산비용 지원은 전국 "여성장애인 출산비용지원"과 다르다.
7. **다문화가족 전용 서비스.** 결혼이주여성, 다문화가족, 외국인만 대상인 서비스는 지금 범위에서 뺀다.

5번과 6번이 애매하면 넣고 note에 적는다.

## 합치기

같은 혜택이 보조금24와 복지로에 둘 다 있으면(기관과 내용이 같으면) 보조금24 쪽을 대표로 넣고 복지로 쪽은 합친다. 이름이 조금 달라도 같은 사업이면 짝이다. 같은 지역에 같은 이름으로 올라온 원본은 후보 목록에서 이미 한 항목으로 묶여 있다.

## 넣을 때 정하는 것

- `audience` (특정 대상만 받으면. 누구나 받으면 빼기): `ADOPTION_FOSTER` 입양·가정위탁, `DISABILITY` 장애, `SINGLE_TEEN_PARENT` 한부모·청소년부모, `LOW_INCOME` 기초생활·차상위 등 저소득, `MULTI_CHILD` 다자녀·다태아(둘째·셋째 이상만 받는 것 포함), `INFERTILITY` 난임·임신 준비, `SICK_CHILD` 미숙아·질환·발달, `SPECIAL` 그 밖의 특정 대상(직업, 나이 등)
- `conditions` (받으려면 갖춰야 하는 조건): `EITHER_PARENT_INSURED` 부모 중 한 명 고용보험 가입(육아휴직 장려금 등), `USES_CHILDCARE` 어린이집·유치원 이용(보육료 등), `HOME_CARE` 집에서 돌봄(가정양육수당 등)
- `name`: 지역 머리말은 명령이 자동으로 뗀다. 그래도 어색할 때만 적는다

## 판단 파일 모양

후보마다 하나씩, 빠짐없이:

```json
[
  { "slug": "gov24-1", "decision": "include", "audience": "MULTI_CHILD", "note": "" },
  { "slug": "bokjiro-wlf1", "decision": "merge", "into": "gov24-1", "note": "" },
  { "slug": "gov24-2", "decision": "exclude", "rule": 4, "reason": "원문 \"초등학생\"", "note": "" }
]
```

`note`에는 애매했던 점만 적는다.
